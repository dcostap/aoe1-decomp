# Review-only probable helper-island report

Date: 2026-04-22

## Goal

Add a second scripted report beyond the safe exact-name/import/prefix lane.

This report is intentionally **review-only**. It does **not** classify anything by
itself. Instead, it proposes compact regions that look like likely toolchain/helper
islands so later work can review candidates instead of rediscovering them manually.

## Output

Generated by:
- `tools\generate_toolchain_supplied_manifest.py`

Written to:
- `build\toolchain_probable_helper_island_candidates.tsv`

## Current heuristic

The report currently emits a row when all of the following are true:

1. there is a contiguous run of currently-`normal` inventory entries,
2. every entry in that run has:
   - no PDB source file, and
   - a generic inventory name such as `FUN_...` or `case...`,
3. the run is small enough to be a plausible compact helper neighborhood,
4. the run is **sandwiched** between existing `toolchain_supplied` anchors within a
   conservative local distance window,
5. and the nearest anchors are not just DLL import thunks.

That means this report favors exactly the kind of unresolved glue that often lives
inside CRT/compiler helper neighborhoods:

- unnamed bridge functions,
- local unwind/dispatch glue,
- small cleanup helpers,
- helper-bank stubs between already-identified runtime anchors.

## Important limitations

This report is intentionally conservative in one direction and permissive in another:

- conservative because it does **not** auto-classify anything,
- permissive because some reported rows will still be false positives.

So the correct use is:

- read the report,
- inspect the packets,
- decide whether a candidate really belongs in a toolchain region,
- then update manifests only after review.

## Why this is useful

The safe hidden-label queue is excellent when a hidden label directly reveals the
runtime helper name.

But some unresolved neighborhoods do **not** expose one clean hidden label. Instead,
what they expose is structure:

- a generic `FUN_...` run,
- no PDB source,
- and clear placement between known CRT/compiler helper anchors.

This report turns that structural clue into a review queue.
