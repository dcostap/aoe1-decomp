## Source

The source owner is `src/Path.cpp`, and the PDB packet assigns
`0046AAE0` to `Path::operator==(const Path&) const` with parameter home `+4`.
`include/path.h` proves `Path` size `0x34`, `pathValue` offset `0x24`, and
`currentSizeValue` offset `0x2C`. `Waypoint` is a typed 16-byte record.

The retained source is the simple direct typed form:

```cpp
for (; i < currentSizeValue; i++) {
    if (other.pathValue[i].x != pathValue[i].x ||
        other.pathValue[i].y != pathValue[i].y ||
        other.pathValue[i].z != pathValue[i].z ||
        other.pathValue[i].facetToNextWaypoint !=
            pathValue[i].facetToNextWaypoint) {
        return 0;
    }
}
```

VC5 emits the original loop read order from this source. Reversing each scalar
operand is not a repair: it changes the loop encodings and keeps the pre-loop
load order wrong. Materializing typed `thisPath` and `otherPath` locals makes
VC5 emit the desired pre-loop order, but it reverses the x87 loop read order,
adds a second count test, changes the register schedule, and creates a
112-byte drift. This source is not retained.
