### Behavior

- `0046B680` and `0046B684` read the 32-bit `x` and `y` parameters.
  `0046B68A-0046B691` forms `x * 255`; `0046B693` arithmetic-shifts `y` by
  two; `0046B696` adds the row to `this`. `0046B69B` reads the packed byte and
  `0046B6A2` keeps its address for a possible write. There are no bounds checks.
- `0046B698` selects `y & 3`; `0046B6A9` reads the shift table. Instructions
  `0046B6AF-0046B6B3` extract one two-bit lane. `0046B6B5` skips the write
  when that byte result is zero.
- Otherwise, `0046B6B7` reads the matching clear mask. `0046B6C3-0046B6CB`
  clears that lane, decrements it, shifts and merges the result, then
  `0046B6CB` writes one byte. Other lanes remain unchanged.
  `0046B6CD-0046B6CF` restore registers and return with `ret 8`.
- `ObstructionValueShift` and `ObstructionValueMask` have source values
  `{0,2,4,6}` and `{0xFC,0xF3,0xCF,0x3F}`. The original listing reports the
  same little-endian table bytes. The function has no calls and returns with
  `ret 8`.
- No runtime boundary test ran. The VC5 output uses the same arithmetic right
  shift and unchecked byte address as the original. Linked table placement
  was not audited.
