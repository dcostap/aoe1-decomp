## Behavior review

This review uses the original inventory, original bytes, PDB symbols, and the
current source. It does not treat the rebuilt executable as an oracle.

- PDB names `theShape`, `shape_num`, `Xpos`, `Ypos`, `Mirror`, and local `X2`.
  It gives `shape_num` type `int` and `Shape_Info` type layout from `Shape.h`.
- Original `+0x06` loads `theShape`. `+0x0A` checks it. `+0x12` loads
  `FShape`; `+0x15` checks it. Both null paths exit without a call.
- Original `+0x1D` loads `shape_num`; `+0x21` loads `shape_info`;
  `+0x24` shifts the index by five. Each selected `Shape_Info` is 32 bytes.
  `+0x2D` loads `Shape_Outline_Offset`; `+0x30` adds `FShape->Version`.
- Original `+0x32` loads `Width`; `+0x35` computes `Width - 1 + Xpos`.
  `+0x3D` loads `Height`. `+0x40` saves `X2` before either loop.
- Original `+0x44` loads `Ypos`; `+0x48` tests `Mirror`.
  The initial row check uses signed `Ypos < Ypos + Height`.
- The normal path reads `start` at `+0x5A`, then `end` at `+0x5D`.
  It clips `line` at `+0x67` and `+0x6C`. It skips negative `start` at
  `+0x71`. It sign-extends both outline values at `+0x7B` and `+0x82`.
  It calls `AddSpan` at `+0x8D` with `(Xpos + start, X2 - end, line)`.
- The mirrored path reads the same pair at `+0xAF` and `+0xB2`.
  It clips the row at `+0xBC` and `+0xC1`. It skips negative `end` at
  `+0xC6`. Its `AddSpan` call at `+0xE2` uses
  `(Xpos + end, X2 - start, line)`.
- The normal loop reloads `Height` at `+0x96`. The mirrored loop reloads it
  at `+0xEB`. Both increment `line` and use a signed comparison.
  This preserves changes to shape metadata that occur during `AddSpan` calls.
- The function has no shape-index or outline bounds check. It keeps 32-bit
  coordinate arithmetic, signed row comparisons, and 16-bit sign extension.
  No behavior defect is proved by this review.

Runtime tests did not run. Linked numeric dependencies remain unknown.
