# Function notes: 0053B300 `LocateIDbyDrawLevel`

Module notes: `decomp_notes/view.md`.

## 2026-09-14 accepted-drift re-review (`drift-007-view`)

### Behavior

Original instructions `0053B300-0053B313` read StartLevel and EndLevel and
swap them only when StartLevel is greater. `0053B315-0053B319` clamp a
negative StartLevel to zero. The function loads `Max_Draw_Levels` at
`0053B31B`, clamps EndLevel at `0053B31E-0053B322`, then checks
StartLevel <= max, EndLevel >= 0, and StartLevel <= EndLevel at
`0053B324-0053B330`.

Only after those tests, `0053B332-0053B340` reads the level-head array and its
first node. A null head advances to the next level at `0053B342-0053B358`.
For each node, `0053B346-0053B34E` compares Object_ID before Node_Type; a match
returns that node. Otherwise `0053B350-0053B355` follows `NextOnLevel`. The
inclusive level loop is at `0053B357-0053B35D`. Failure returns null at
`0053B35F-0053B364`. The source preserves this order and does not write memory
or make calls. No behavior defect was found.

Malformed list pointers and externally changed bounds were not runtime tested.
The source retains the original access order and does not add bounds checks.
