# `TRIBE_World::data_load_players_type` — `0052E220`

## Behavior

The original body spans `0052E220-0052E2AC` and contains 141 bytes. The PDB
records signed `short` parameters at stack offsets `+4` and `+8`, followed by
`FILE*` at `+0xC`.

The original tests whether `type` equals one. Other values call the base
implementation with `id`, `type`, and `infile`, then return. Type one allocates
`0x2C` bytes for `TRIBE_Master_Player` and passes `infile` to its constructor.
The function stores the returned pointer, including null, at
`master_players[id]` (`this+0x48`). It has no bounds check.

The source uses `if (type != 1)`. This preserves the predicate for every
`short` value. The base call, allocation, constructor argument, null result, and
indexed store match the original effects and order.
