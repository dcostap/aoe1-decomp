### Behavior

The function seeds a local stack from the map stack offsets. It clamps the
group-area bounds, marks the search rectangle, and computes the randomized
placement count. It pops cells, aligns and checks each candidate, creates an
object when placement fails, clears the accepted cell, and pushes up to four
unvisited neighbors. It repeats until the stack is empty or the count reaches
zero, then deinitializes the stack.

The executable stores zero into both local stack links before `init_stack`.
The helper then writes all six stack fields before later use. Existing pair,
single-link, aggregate, constructor, and named-zero probes changed the local
memory and register model but did not establish a safe canonical source.
