# 00438670: minimap scroll start

The original executable is the behavior oracle.
`RGE_Diamond_Map::start_scroll_view` owns `00438670` through return `00438712`.
Natural source: `src/diam_map.cpp`.

The original calls `pick_tile` at `00438693` and tests its result.
On success, it captures the mouse and sets the scrolling flag.
It converts both signed-short tile coordinates to float, then subtracts the value at `0056F608`.
The subtraction instructions are at `004386B6` and `004386D8`.
The four bytes at `0056F608` are `00 00 00 BF`: float **−0.5**, not +0.5.
The original therefore adds half a tile before calling `RGE_Player::set_view_loc` at `004386E1`.

The recovered source incorrectly subtracted positive 0.5 from both coordinates.
This caused a one-tile camera offset on both axes during the accepted human replay at world-update call 106.
Original: `(70.5, 120.5)`. Rebuilt: `(69.5, 119.5)`.
The repair uses natural additions of `0.5f`. Signed-short values plus a half are exactly representable in float.
Redraw calls, capture, scrolling state, and last mouse coordinates remain unchanged.

The companion function `00438720` contained the same constant-sign error.
Runtime validation and build evidence belong in `decomp_notes/human_rebuilt_replay_20260914.md`.
