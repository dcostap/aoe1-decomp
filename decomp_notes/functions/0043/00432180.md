## 00432180 `DPEnumCallback`

- PDB source: `com_serv.cpp`, lines 123 to 162.
- Original size: 125 bytes.
- Historical result: exact before module migration.

The callback stores the name and GUID at the current service count. It creates
an `IDirectPlay` object. On success, it sets the service active, calls `Release`,
and increments the count. On failure, it clears the active flag and increments
the count.

`IDirectPlay::Release` is a virtual `__stdcall` method. This call convention is
required by the observed COM dispatch.

### Module migration

`src/com_serv.cpp` keeps the direct virtual call. It replaces the callback
fragment and its context macro.
