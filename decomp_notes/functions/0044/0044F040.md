# 0044F040 `InfluenceMap::maxValue`

## Accepted drift review

The `connectionsIncluding` recovery changes the VC5 translation-unit compiler state. `maxValue` now differs by two operand bytes.

The original loads `xSizeValue` and multiplies by `ySizeValue`. The rebuild loads `ySizeValue` and multiplies by `xSizeValue`.

Integer multiplication is commutative. Both forms read the same two fields and produce the same value. They have no calls or memory writes before the reads. If either field address faults, both forms fault at that same address without an earlier observable effect.

All remaining instructions match. Size, frame, saved registers, branches, returns, ownership, boundaries, and relocations also match.

This accepted drift is complete. No further matching work is required without new source, behavior, ABI, or compiler-context evidence.
