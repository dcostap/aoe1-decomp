# Function notes: 0047E2A0 `get_text(long)`

## Re-review, 2026-09-28

### Behavior

- Original body: `0047E2A0`–`0047E2DC`, 61 bytes. `0047E2A0` reads
  `this->list` at `this+0xF4`; `0047E2A6` sets a 32-bit index to zero.
- For a null list, `0047E2AA` branches to `0047E2CE`. That path clears the
  byte at `0086B250`, returns its address, and uses `ret 4`.
- For a nonnull list, `0047E2AC` loads the `long` argument. At `0047E2B0`, the
  function compares the index with the argument. On equality, `0047E2C9` reads
  the first pointer in the node (`text`) and returns it. Otherwise,
  `0047E2B4` reads `next_node` at node offset `0x0C`, `0047E2B7` increments
  the index, and `0047E2B8` stops at a null node.
- The out-of-range path at `0047E2BC` writes `AL` to `0086B250`. The preceding
  `TEST EAX,EAX` and taken null branch at `0047E2B8` prove `AL` is zero. It
  then returns the same static byte. A negative index also reaches this path
  for a finite ordinary list. There is no runtime test for very large lists
  or counter wraparound.
- PDB scoped symbols identify `0086B250` as this function's static `char`
  `empty_text`. The separate `get_text2(long)` static is at `0086B24C`.
  These buffers do not alias in the original.

### Source

- `src/Pnl_txt.cpp` traverses the same list, compares the same index, returns
  the node's text pointer without checking it for null, and clears the same
  function-local static byte on both empty paths.
- The source uses `while (node != 0)`. The original starts its loop after a
  null-list guard. The compiler emits the same loop shape for this source.
- The inspected `0053C4D0` candidate patch uses the same list loop and a
  function-local empty byte. It adds MBCS type casts elsewhere; it gives no
  better source form for this target.
- One evidence-backed probe changed `line_in == i` to `i == line_in`, which
  matches the Ghidra expression. It worsened the target from three to four
  differing bytes. A do-while probe matches the Ghidra loop form but worsened
  the target to 38 differing bytes. Neither change remains.
