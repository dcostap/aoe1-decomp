## 2026-09-28 behavior review: drift-024-Pnl_scbr

### Behavior

- The full original listing is in `inventory/functions/0047/0047AB20_set_tab_pos.txt`.
  The function receives one signed `long` parameter and returns with `ret 4`.
  It saves EBX, ESI, and EDI.
- At `0047AB29` and `0047AB2F`, the body reads `orientationValue` and `list_len`.
  It writes the input value to `list_num` at `0047AB38`.
  The field offsets are `+0x1B4`, `+0xF8`, and `+0x104`.
- When orientation equals one, positive `list_len` enables the horizontal mapping.
  The body reads `tabSize`, `tab_min_x`, and `tab_max_x` at `0047AB44`-`0047AB59`.
  It multiplies by the signed input and divides by positive `list_len` with `idiv`.
  It stores the result in `tab_x` at `0047AB67`.
- The divide-by-two uses `cdq`, `sub eax,edx`, then `sar eax,1`.
  This sequence rounds negative odd values toward zero.
  `imul` keeps the low 32-bit product before the signed divide.
  The source uses the same signed 32-bit fields and parameter.
- Horizontal clamping always runs, even when `list_len` is not positive.
  Values below `tab_min_x` become the minimum at `0047AB7D`.
  Otherwise, values above `tab_max_x` become the maximum at `0047AB8F`.
  The signed comparisons and `else if` order matter when bounds are unusual.
- The vertical path skips recomputation when `list_len` is not positive.
  For a positive length, the final list item sets `tab_y` to `tab_max_y` at
  `0047ABA2`-`0047ABA8`. Other items use the matching signed formula at
  `0047ABB0`-`0047ABD3`. The body then clamps `tab_y` at `0047ABD9`-`0047ABF3`.
- Both orientations call `calc_item_rects` directly at `0047ABFB`.
  The function then pushes one and calls vtable slot `+0x20` at `0047AC06`.
  The receiver is `this`. It restores EDI, ESI, and EBX, then returns at
  `0047AC0C`.
- No behavior defect was found in the tested source. Zero or negative lengths
  preserve the old position before clamping. The vertical final-item special
  case also remains intact. No runtime tests were run. Object-address faults
  and concurrent field mutation were not tested.

  The fields used here are also `long`.

  It expresses the formulas with the declared `long` values. On this 32-bit
  toolchain, the compiler emits the same machine bytes.
- The baseline source state used the casts and local. The recorded child state
