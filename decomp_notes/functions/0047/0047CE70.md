# Function notes: 0047CE70 `calc_draw_info`

## Re-review, 2026-09-28

### Behavior

- Original body: `0047CE70`–`0047D05F`, 496 bytes. `0047CE7B` loads
  `font_height`; `0047CE83`–`0047CE86` stores `font_height + 2` at `this+0x140`.
  If the font height is zero, `0047CE8E` sets `draw_lines` to one and skips
  division.
- Otherwise, `0047CE97`–`0047CEAE` reads `spacer_size`, `border_size`, and
  panel height. The zero-spacer path subtracts twice the border size. The
  nonzero-spacer path also makes the divisor `font_height + 2*spacer_size + 1`:
  `0047CEB2`–`0047CEBB` computes that value. `0047CEBF`–`0047CEC2` uses signed
  `IDIV` and stores its low word. A zero divisor or quotient overflow faults
  before later field writes. These fault cases have no runtime test.
- `0047CEC9`–`0047CED2` clamps `draw_lines` to at least one. `0047CED9`–
  `0047CF1A` clamps `top_line` against `num_lines`, available lines, and zero.
  `0047CF2C`–`0047CF77` computes and clamps `bot_line`. `0047CF5D`–`0047CF77`
  clamps `cur_line` to the range produced by the original instruction order.
- For zero `num_lines`, that order matters. `top_line` becomes zero, then
  `bot_line` and `cur_line` can become `-1`. The source preserves this result.
- `0047CF7E`–`0047CF86` returns through the common exit if `scbar_panel` is
  null. When `update_scbar` is nonzero, `0047CF8C`–`0047CF9A` calls
  `0047AC10` with `num_lines - draw_lines + 1` and `top_line`.
- `0047CF9F`–`0047CFC3` gates auto-scrollbar work. When more lines exist and
  the scrollbar is inactive, `0047CFC9`–`0047CFF8` calls direct
  `TPanel::set_rect` with width `full_width - scbar_width`, then sets
  `scbar_active`. If the text panel is active, `0047CFFC`–`0047D016` calls
  vtable slot `+0x14` with `1`, stores `pnl_wid` in `text_wid`, and returns.
- When lines no longer require the scrollbar, `0047D019`–`0047D03A` restores
  `full_width` and clears `scbar_active`. If active, `0047D044`–`0047D04D`
  calls the same vtable slot with `0`. The common exit at `0047D050`–`0047D05F`
  stores `pnl_wid` in `text_wid` and returns.
- The original call setup at `0047CF92`–`0047CF9A` passes
  `(num_lines - draw_lines + 1, top_line)` to `set_list_len`. At
  `0047CFD9`–`0047CFE6`, `set_rect` receives
  `(pnl_x, pnl_y, full_width - scbar_width, pnl_hgt)`. At
  `0047D01D`–`0047D032`, it receives `(pnl_x, pnl_y, full_width, pnl_hgt)`.
  The virtual calls pass `1` at `0047D002` and `0` at `0047D04A`.
