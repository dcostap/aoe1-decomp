## Runtime turning repair

Base commit: `776a98204`.
After the civilian-selection repair, a random game hangs at rebuilt `00451D21`.
The captured thread runs inside the first turning loop.
Evidence: `build/crash/map_setup/idle_hang.dmp` and `idle_hang.log`.

The original PE confirms the branch sequences at `0045EBBD` and `0045F3B4`.
Each compares angle delta with zero, then tests x87 C0 through `AH & 1`.
For nonnegative angles, branches `0045EBE0` and `0045F3D7` select subtraction of `DAT_00570b60`.
That original float is positive one. Negative angles subtract `DAT_00570b64`, which is negative one.
The source reversed these constants in both loops. Each step increased the error magnitude.
With zero turn speed, the timer could not terminate the loop.
The repair restores the original constants without changing the angle update or adding a loop limit.

## Passable movement and elevation repair

Base commit: `fc8ca9c87`.
Runtime accepts a villager movement command, but the villager does not reach the selected point.
Source review found two further defects in this function.

Original `0045ECB3` jumps directly to `0045F55C` when the first movement step is passable.
The source instead ran path recovery on that path.
The repair extends the existing blocked-movement scope over path recovery and its second movement test.
Passable movement now reaches the common movement tail directly.
Blocked movement retains the existing collision delay, target range, path limits, and waypoint recovery paths.

Original `0045F55C` reads the old `world_z`; `0045F567` saves it before any tail teleport.
Original `0045F706` subtracts the new `world_z` from that saved value.
The source used the destination height and left that variable uninitialized on the waypoint-snap path.
The repair saves `oldZ` at the common tail entry and uses `oldZ - world_z` afterward.
The destination height still controls ordinary teleport calls. Waypoint snapping still uses waypoint height.
This replaces the unsupported stale-stack claim in the source.
Older notes that describe a guaranteed zero snap delta are also too broad: teleport can change height.

The target remains MISMATCH: 3722 bytes versus 3704, with 2905 differing bytes.
No exact or whole-function equivalence claim is made.
