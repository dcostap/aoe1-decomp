# 0045A6D0: map point conversion

`RGE_Map::get_point` owns the original span `0045A6D0` through return `0045A734`.
Natural owner: `src/map.cpp`.

The original computes X from `(param_4 + param_3) * tile_half_width`, then adds the supplied X origin.
For Y, instruction `0045A6F8` subtracts the float at `005706EC` from `param_4`.
The four data bytes are `00 00 80 BF`: float **−1.0**, not positive 0.5.
It then subtracts `param_3` and `param_5`, multiplies by `tile_half_height`, and converts to integer.
Instruction `0045A728` adds the supplied Y origin and subtracts 16.
Both final stores retain only the low 16 bits.

The source incorrectly used `param_4 - 0.5f`.
The repair uses `param_4 + 1.0f`. It retains the remaining operation order, conversion, origin addition, and final subtraction.
Do not cancel the added unit against the final 16. The function accepts floats and uses runtime tile dimensions.
