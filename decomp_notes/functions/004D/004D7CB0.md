# Unit history writer selection

It compares that byte with the player ID and also permits `0xFF`.
The permitted writer saves 44 bytes from `unitHistory`.

`TRIBE_World::controllingComputerPlayer` owns offset `+0x11D`.
The old source read `RGE_Game_World::player_turn` at `+0xB0` instead.
Use the derived world field, as `addObjectMemory` already does.
Keep the unsigned byte, player comparison, and `0xFF` case unchanged.

The reported chaos replay matched simulation observations but wrote zero unit-history counts.
