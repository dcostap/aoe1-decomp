# Verified-logic function bank

This directory contains normal C/C++ functions whose exact VC5 assembly matching
was suspended only after substantial documented work and whose reconstructed
behavior was then subjected to repeated independent review against the original
executable.

These functions are not exact matches. Each source must retain its matching
attempt log and have a complete ledger under `logic_reviews/`. Promotion is
controlled by the designated main agent under `docs/main_agent_workflow.md`.
