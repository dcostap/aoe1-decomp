### Behavior

Let S denote ESP after the prologue and saved-register pushes.
The original saves the promoted short index at `S+0x14`.
It passes `S+0x18` to `GetTextMetricsA` and later reloads the index from `S+0x14`.
The API output therefore cannot replace the index.

The restoring `SelectObject` arguments lower ESP by eight bytes before the metrics reads.
The three reads use metrics offsets `0x14`, zero, and `0x10`.
These are average character width, height, and external leading.
The correct stores use `fonts[i]`, `tmAveCharWidth`, and `tmHeight + tmExternalLeading`.

The old interior-pointer interpretation starts the metrics object four bytes too early.
Its shifted field names describe a decompiler artifact, not the original API structure.
PDB scoped records independently support separate `short i` and `tagTEXTMETRICA tm` objects.

The retained source preserves both allocation arguments, member stores, and allocation-failure return.
It preserves DC acquisition and the allocation leak on DC failure.
The short loop counter, bound reads, switch table, nine font calls, IDs, and flags agree.
Null fonts skip selection and all metric stores. Non-null fonts follow the original call sequence.
The code ignores the metrics API return, as the original does.
Selection restoration, DC release, and all three return paths agree.
