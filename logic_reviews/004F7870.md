### Repeated soldiers

Original `004F7C3C` and `004F7CB2` branch to `004F7D55` when the working array already contains the ID.
That destination increments the result count.
The previous main source instead jumped past the increment in both nonzero-flag soldier branches.

With two qualifying soldiers that have ID 42, the original returns two and stores one working ID.
Previous main returned one for either nonzero flag.
The zero-flag branch and the warboat branches already counted duplicates correctly.

The public `add` operation rejects duplicate insertion. The caller increments `count` regardless of that return value.
This restores the original difference between the result count and the unique working-array count.
The soldier-only query retains the same behavior at `004F7770` and `004F785D`.

### Empty tasked lists

Original `004F78F2..004F7910` checks the second warboat subscript before testing the tasked count.
Original `004F7B6D..004F7B8D` does the same for soldiers.
Both can call `004147A0 resize` before an empty membership search exits.
Previous main moved these subscript operations inside the membership loop.

For index one and capacity one, a failed first growth can leave the old readable ID storage in use.
The original can retry growth after the object and unit-AI checks, even when the tasked count is zero.
Previous main skipped that retry. The repaired source evaluates the subscript before calling `contains`.
The membership scan itself still avoids element reads for an empty count.

### Retained operations

Both queries retain the signed flag and priority tests:

- Negative flag: accept no current action, or a priority below the limit.
- Positive flag: require a current action and a priority above the limit.
- Zero flag: require a current action and an equal priority.

They retain the short-circuit getter order and repeat `unitAI()` at the original stages.
Original `004C7420`, `00413960`, and `00413940` are read-only pointer or integer getters.
The warship query scans warboats before soldiers and retains the 16-bit soldier group tests for `0x12` and `0x0D`.
The soldier query clears the working count only when its third argument equals one.
The warship query always clears it.

Public subscript, membership, and add operations replace expanded implementations.
They retain signed bounds, bounded copies, deletion after successful allocation, and count reloads after array writes.
They do not add a failure check that the original caller lacks.
These repairs do not establish every remaining instruction-level fault or alias relation in either complete body.
