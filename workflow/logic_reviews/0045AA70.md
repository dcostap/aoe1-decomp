# Logic review: 0045AA70 `RGE_Missile_Object::missile_move`

The canonical Action and Moving Object vtables change two x87 operand orders.
Both bodies have 172 bytes, 60 instructions, a `0xC` frame, five conditions,
two returns, and the same two calls. Owner, boundary, relocations, and saved
registers agree.

The original loads each position field before its movement field. The rebuilt
code loads the movement field first. Each pair uses `fadd` and writes the same
sum. Both reads use one valid missile object. Game position and movement fields
are finite supported values. Thus, the load order cannot change a fault or
result for supported objects.

Root approves `accepted_drift`. This change follows the PDB and binary vtable
evidence. Review is complete. Do not recover unsupported overloads to restore
these 16 bytes.
