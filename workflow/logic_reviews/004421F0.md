# Semantic review: 004421F0

Result: accepted drift.

## Cause

The executable build removes the unsupported explicit `RGE_Doppleganger_Object` destructor declaration.
The original destructor at `00441A60` only jumps to `RGE_Static_Object::~RGE_Static_Object` at `004C1290`.
The compiler now owns this implicit destructor.
This declaration change alters register allocation in the neighboring `add_doppleganger_check` function.
The function body itself is unchanged.

## Original evidence

Oracle: `orig/empiresx.exe`.
Original SHA-256: `88a0392120280c1b91ee90fe6f7cf50c72e55149a16c9b1ca79505572b8b9c90`.
Tested base: `f31347147`.

`check_function.py --va 004421F0 --detail full --no-history` reports four differing bytes.
Both bodies have 185 bytes, 73 instructions, two calls, and three returns.
Ownership, boundaries, and all four relocations pass.
All bytes outside offsets `+46`, `+49`, `+4C`, and `+50` remain equal after validated relocation resolution.

## Register and memory proof

Only the block at `+45..+54` differs.

Original:

```text
mov ecx,[edi+0Ch]
mov edx,[esi]
mov ax,[ecx+4Ah]
cmp ax,[edx+4Ah]
je +5B
```

Rebuilt:

```text
mov edx,[edi+0Ch]
mov ecx,[esi]
mov ax,[edx+4Ah]
cmp ax,[ecx+4Ah]
je +5B
```

The register names change. The addresses, access widths, access order, comparison operands, flags, and branch remain equal.
Neither block writes memory or calls another function.
Thus both blocks have equal memory effects, exceptions, and memory-fault order.

On the unequal branch, both functions return zero without reading ECX or EDX again.
On the equal branch, `+5B` replaces EDX with `[esi+8]` before its next use.
The following paths replace ECX at `+68` or `+77` before its next use.
The changed register values therefore cannot reach an observable result.
The ABI permits these caller-saved register differences.

All other instructions, calls, stores, return values, cleanup, and control flow remain unchanged.
No floating-point instruction changes.

## Decision

Accept the canonical destructor recovery and this behavior-equal register difference.
Do not add source scheduling code to restore the previous register names.
No further matching work is required without new behavior, ownership, type, or source evidence.

Closure report: `build/audits/executable_implicit_destructors/report.json`.
The complete 224-module audit found only this matching regression.
