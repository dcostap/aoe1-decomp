# Function notes: 004348F0 `do_command_add_attribute`

## Binary facts

The original span is 40 bytes with one virtual call and no frame. Its first
instruction loads the argument home, `[esp+4]`. Its second instruction loads
`this->world`, `[ecx+4]`.

The rebuilt body reverses these two loads. All later instructions, including
the player lookup, three argument pushes, slot-`0x78` call, register restore,
and `ret 4`, match the original. The target and boundary also match.

## Current result

The clean natural translation-unit baseline is `MISMATCH`, 5 strict bytes
(12.5000%), with 40/40 bytes, 16/16 instructions, no frame, one aligned
virtual call, matching ownership, boundary, relocations, and target.

Historical direct-chain source, the PDB parameter name, packet aliases,

## Fault-order review

The first original load reads the pointer value from the stack. It does not
read `param_1` fields. Therefore, an invalid packet pointer with a readable
argument home does not change the first fault. Both bodies reach the packet
field read after both initial loads.

The two bodies differ for invalid memory at the initial load addresses. With
an unreadable `this` and a readable argument home, the original reads the home
first, then faults at `mov ecx,[ecx+4]`. The rebuild faults at its first
instruction before reading the home. With an unreadable argument home and a
readable `this`, the original faults first at `[esp+4]`; the rebuild reads
`this->world` first. A handler can observe the different fault address,
instruction, and register state.

This is a real behavior difference for malformed calls. It is not safe to
call the bodies behavior-equal when the review includes unreadable stack or
`this` memory. No runtime malformed-input test was run. The instruction trace
is sufficient to prove the ordering difference.

## Repair review

The tested natural source forms did not direct the scheduler to this order.
A volatile packet view produced the two desired initial loads, but it changed
the body to 45 bytes, added floating-point operations, changed the
register-save shape, and changed later load order. It is artificial and is
not retained.

The final classification is **blocked**: no exact, natural, policy-compliant
source repair is proven, and the old accepted-drift proposal is withdrawn.
Keep the natural source as the best source reconstruction. Revisit only with
original source or a supported full-translation-unit context donor.
