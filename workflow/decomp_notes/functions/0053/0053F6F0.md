  `C:\msdev\work\age1_x1\vw_main.cpp` and line `1314`. It precedes the
  timing-slot read and both view-pointer reads.

  `color_log('L','L',1)`, direct `RGE_View::draw()`, then
  `color_log('L','_',1)`. It reads `do_draw_log` again before optional
  `<vf>\n` logging.

  `TDrawArea::Clear` next. Its receiver is `render_area`; its arguments are
  `&clip_rect` and zero-extended byte `color`. Then virtual slot `+0x2C` runs
  without arguments.
- `include/panel.h`, `src/Panel.cpp`, and `src/drawarea.cpp` support these call
  roles and effects. `draw_setup(0)` sets clipping. `draw_finish()` clears
  redraw state and clipping.

  passes line `1346`. The function adds elapsed-outside-render time to slot
  `6`, increments `view_update_count`, then adds render time to slot `0xC`.
- `get_accum_time` returns `timings[id].accum_time`. `add_to_timing` adds an
  unsigned 32-bit value and stores `last_single_time`. It updates `max_time`

- The timer helper returns its debug counter or WinMM time. Timing calls use
  `rge_base_game` as receiver. The original reloads this global for each call.
- The timing value is `(timer_end - timer_start) - (accum_end - accum_start)` modulo `2^32`. The accumulated delta also goes to slot `0xC`. Unsigned widths preserve timer wraparound.
- Original and rebuilt code keep the same branches, calls, arguments, memory

- Original and rebuilt code keep the same call and memory-fault order. The function has no loop or local pointer alias.
- No later branch reads the changed subtraction flags. The `add_to_timing` callee sets its own flags before its conditional branch. Neither subtraction accesses memory or traps on overflow.
- The instruction trace covers null world, null player, both logging values, and unsigned timer wrap. Runtime UI and fault-injection tests were not run.
