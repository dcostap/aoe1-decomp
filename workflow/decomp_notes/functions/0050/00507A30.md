## Dispatch repair, 2026-09-16

### Defect

The rebuilt switch sent 195 event types to `return 2`.
The original sends only 28 of them there. The other 167 fall through to the default body.
That body clears the current target, stops the object, and notifies the commander.
The rebuilt source therefore skipped cleanup for 167 event types.
