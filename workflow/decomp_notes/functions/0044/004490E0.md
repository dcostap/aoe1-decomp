### Source

`include/effects.h` proves 44-byte effects and 12-byte commands with static
size checks. The source uses the reviewed field layout and the PDB `int index`.
It also preserves the first-name overwrite and the signed-short command count.

The source now stores the allocated command pointer before its repeated count
guard. This preserves the original store on the guard's false path. The original
compares before storing; VC5 emits the store before the compare from this natural
source form. The two operations access disjoint fields in the valid allocated
record. An asynchronous write to the count between these operations remains
untested.
