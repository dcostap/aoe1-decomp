- Map types `0,1` set `b[0x58]` and `b[0x59]` to `200`; types `2,6,8,5` set them to `100`.
- The current source writes the same indices and values for every branch.
- The caller has `buildLists[125]`. Minoan writes no index above `0x59`.
- Original calls are `logCommonHistory`, `deathMatch`, and `difficulty`, at `0051809C`, `005180AA`, and `00518129`.
- The source calls use those same methods in that order.
- PDB places `b` at stack `+4` and `mapType` at `+8`. Map tests use full 32-bit values.
- The difficulty test is signed. Every return uses `ret 0x10` for four stack arguments.
