## 2026-09-28 reopened behavior review: drift-024-Pnl_scbr

### Behavior

- The original body and PDB map are in
  `inventory/functions/0047/0047B970_draw_button_pic.txt`. At `0047B978`, the
  body loads `button_pics`; `0047B981` branches to fallback when it is null.
  It loads `frame` at `0047B987` and branches to fallback only when it equals
  `-1` at `0047B98B`.
- The normal path saves the incoming `rect` pointer in ESI at `0047B994`. It
  calls `TDrawArea::SetClipRect` at `0047B99C`, then calls
  `TShape::shape_minmax` at `0047B9BC`. Clipping occurs before shape bounds
  are read.
- `shape_minmax` receives four distinct four-byte output ranges. Relative to
  this function's entry stack pointer, they are `-12`, `-4`, `+12`, and `-8`
  for formal outputs one through four. At `0047B9A1`, the first LEA points to
  entry minus eight. After the frame push, `0047B9A6` points to entry plus
  twelve. The next LEA at `0047B9AB` points to entry minus four. After that
  push, `0047B9B6` points to entry minus twelve. The final push order gives
  the four formal outputs listed above. The third output therefore writes four
  bytes to the incoming `rect` argument home at `+12`; it does not write
  through the RECT pointer. The range does not touch the return address at
  `+0`, the `frame` and `down` homes at `+4` and `+8`, or a saved register.
  ESI still holds the original RECT pointer for later reads.
- The callee packet at `inventory/functions/004B/004B9070_shape_minmax.txt`
  shows that negative shape numbers return at `004B907A` without writing the
  outputs. A failed `Check_shape` also returns before the output writes. The
  caller ignores this return value and still reads the scratch values. Thus
  `frame == -1` takes fallback, but values below `-1` enter the normal path
  and use unwritten outputs. The source leaves these values uninitialized.
  This original edge behavior must not be repaired by initialization.
- The x/y calculations use signed division, narrow results to 16 bits, and
  sign-extend them before `shape_draw`. The original applies the down offset
  with `inc ecx` and `dec edi` at `0047BA19`-`0047BA1A`, then adds the boolean
  down flag to the frame at `0047BA21`-`0047BA26`. `shape_draw` receives the
  render area, signed-short x/y, adjusted frame, flags zero, and color table
  zero at `0047BA3F`.
- The fallback loads `parent_panel` at `0047BA4E`, reads the RECT argument at
  `0047BA51`, and calls virtual slot `+0x3C` at `0047BA58`. There is no null
  check for `parent_panel`. Both paths restore EBX, EBP, ESI, and EDI and return
  with `ret 0x0C`.
- The only instruction difference is at `0047B9EC`. The original subtracts
  the shape term, loads a stack local, then adds `RECT.left` to the low word.
  The rebuild adds `RECT.left` first, loads the stack local, then subtracts.
  The two sequences give the same low 16-bit x value before sign-extension at
  `0047BA2D`. The moved operations add no call or branch. `RECT.left` was
  already read at `0047B9CB` before this second read. The stack local is inside
  the reserved frame. With a valid frame and RECT pointer, these reads add no
  new fault-order difference. No runtime tests were run. Concurrent mutation
  and invalid stack state were not tested.
